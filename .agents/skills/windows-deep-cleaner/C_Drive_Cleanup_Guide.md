## 🛠️ 三步快速清理方案（下次使用时参考）

### 第一步：运行一键清理脚本
你可以使用已放至桌面的 **`Antigravity一键深度清理.bat`**：
1. 双击运行它。
2. 弹出管理员权限确认（UAC）时点“是”。
3. 脚本会自动安全清理：Windows 临时文件、回收站、Windows 更新安装包缓存、Edge/Chrome 浏览器缓存等 12 项系统垃圾。

### 第二步：运行 App 靶向清理
在本项目目录下，运行 `powershell -File scripts\simple_clean.ps1` :
* 自动强杀并清理 **WPS 广告插件目录**、**AI 客户端日志**、**VS Code 编译残留**。

### 第三步：人工介入大头
1. 检查 `C:\Users\杰文\Downloads`，清理旧的下载文件。
2. 检查**夸克网盘**是否还需要保留。
3. 在**微信**、**企业微信**、**飞书**软件设置里，手动点击“清理缓存”。
